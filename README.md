# Алгоритм кодирования-декодирования по методу Хаффмана

**Алгоритм Хаффмана** - это метод сжатия данных, основанный на создании префиксных кодов переменной длины, где частым символам присваиваются короткие битовые последовательности, а редким - длинные. Это достигается построением бинарного дерева Хаффмана из частот символов и последующим кодированием/декодированием с его помощью. 

## сборка и запуск
```
cd .../huffman/src
javac huffman.java
java Huffman encode input.txt encoded.huff
java Huffman decode encoded.huff decoded.txt
java Huffman encode input1.txt encoded1.huff
java Huffman decode encoded1.huff decoded1.txt
```
## описание
- программа полностью управляется из командной строки
- в качестве тестовых примеров для кодирования показаны следующие:
  1. текстовый файл состоящих из 10 одинаковых символов input.txt: "aaaaaaaaaa"
  2. текстовый файл длины 20 байт, состоящий из 3-х различных символов, каждый из которых встречается 10, 5 и 5 раз input1.txt: "aaaaaaaaaabbbbbccccc"
- также есть два бинарных файла Node.class и Huffman.class
